# 🚀 Roadmap Recommendation Platform 
👉 http://infoledge.duckdns.org

A web platform that offers curated resources and personalized learning guidance across popular educational websites like **Udemy**, **Coursera**, **IBM**, **freeCodeCamp**, and more.  

This platform empowers learners by combining **machine learning recommendations**, **AI-powered assistants**, and **interactive coding environments** into one unified space.  

---

## ✨ Features  

- 🔍 **ML-based Recommendation Engine** – Suggests personalized roadmaps based on user preferences and learning goals.  
- 💬 **RAG-Powered Chat Assistant** – Handles user queries and dynamically suggests relevant resources.  
- 📊 **AI-Powered Flowchart Generator** – Uses **LangChain** and **Mermaid.js** to visualize learning paths.  
- 💻 **Interactive Coding Environment** – Built with **CodeMirror**, supporting **Python, C++, and Java**.  
- 📚 **Curated Learning Resources** – Aggregated and categorized content from multiple sources via **Web scraping** and **Kaggle datasets**.  
- 🔑 **Secure Authentication** – Integrated **Google authentication** and **JWT-based authentication** for user access and session management.  

---

## 🛠️ Flowchart Generation  

The platform provides **AI-powered roadmap visualization** using **LangChain** and **Mermaid.js** syntax.  
This allows learners to **see their personalized learning path as a flowchart**.
